# Morsa

Morsa es una CLI para Linux orientada a metadatos, OSINT, reconocimiento y análisis de superficie, inspirada en FOCA.

El estado actual es `0.1.0-alpha.1`: ya existe un flujo vertical funcional de workspace, SQLite, ingesta, extractores iniciales, correlación, reportes y pools de proxies rotatorios. La API pública todavía no es estable.

Consulta `README.md` y `morsa --help` para compilación y comandos disponibles.
